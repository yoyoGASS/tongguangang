# 通關港

準備 **116 年專責報關人員普通考試**的練習系統。

單一 HTML 檔，沒有後端、沒有相依套件、不需要安裝。

## 線上使用

開網址就能用。作答紀錄存在你自己的瀏覽器裡（localStorage），
不會上傳到任何地方，換裝置不會跟著走——要搬家請用「設定 → 進度備份」匯出／匯入。

## 內容

- **1,280 題單選**：108–115 年四科，全部附考選部公告的標準答案（含更正答案與送分題）
- **83 大題申論**：附四段作答架構
- **間隔複習**：答錯歸零、答對升格，間隔依考試日期推算
- **抽驗定位**：40 題（每科 10 題）測出四科強弱，報告會自己講出統計限制
- **高頻考點**：64 組跨年度重複出現的考點與歷年正解對照
- **答錯陷阱診斷**：從選項文字推導，判不出來就不講

四科：通關實務概要、關務法規概要、稅則概要、關務英文。

## 題目來源

考選部「考畢試題查詢平臺」公開釋出的歷屆試題與標準答案。
每一題都保留來源檔名與 PDF 頁碼，可以回頭核對原始試題。

108 年以前的題目不列入練習（法規可能已修正），僅在高頻考點頁作為歷年對照。

## 隱私

沒有伺服器、沒有帳號、沒有追蹤。所有資料都在你的瀏覽器本機儲存空間裡。
